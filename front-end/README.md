# LK-group — Front-end visiteur

Site React (Vite) de LK-group : vitrine entreprise + portfolio développeur, PWA, thèmes clair/sombre.

## Lancer

```bash
cd front-end
npm install
npm run dev
```

Ouvrir `http://localhost:5173`.

## PWA

- Visiteur : manifeste `public/manifest-client.webmanifest`
- Admin (en pause) : `/admin` + `public/manifest-admin.webmanifest`

Les liens des projets se branchent dans `src/data/content.ts` (champ `link`).
